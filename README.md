# Rock Paper Scissors Game 🎮

A simple and interactive **Rock Paper Scissors game** built using HTML, CSS, and JavaScript.

The player chooses Rock, Paper, or Scissors, and the computer randomly selects its choice. The game then determines the winner and updates the score.

## 🎯 Features

- Player vs Computer gameplay
- Random computer choice
- Win, lose, and draw detection
- Live score tracking
- Reset game button
- Interactive choice buttons
- Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Choose one of the three options:
   - 🪨 Rock
   - 📄 Paper
   - ✂️ Scissors

2. The computer will randomly choose an option.

3. The game determines the result:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock

4. Your score and the computer's score are updated automatically.

5. If both choices are the same, the round is a draw.

6. Click **Reset Game** to start the score again from zero.
